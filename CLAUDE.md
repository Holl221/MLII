# ML-агент для табличных данных

Проект для конкурса Альфа-Банка. Задача трека: «Разработайте ИИ-агента, который
самостоятельно строит и улучшает ML-решения под разные задачи».

Команда — студенты 1 курса, поэтому код должен быть простым и понятным новичку.

## Фокус прототипа

- Данные: таблицы в формате CSV.
- Задачи: бинарная классификация, многоклассовая классификация, регрессия.

## Окружение

- ОС: Windows, оболочка PowerShell.
- **Python 3.12** (на 3.14 lightautoml не ставится: нет сборки `statsmodels<=0.14.0`).
- Виртуальное окружение: `.venv` (создано через `py -3.12 -m venv .venv`).
- Запуск тестов: `.\.venv\Scripts\python.exe -m pytest`
- Зависимости: `requirements.txt`. Секреты хранятся в `.env` (шаблон: `.env.example`).

## Архитектура

Все модули лежат в `src/`:

| № | Модуль | Назначение |
|---|--------|------------|
| 1 | `data_profiler.py` | Анализ датасета: типы колонок, пропуски, тип задачи |
| 2 | `baseline.py` | Базовая модель через LightAutoML и её метрика |
| 3 | `llm_client.py` | Обёртка над LLM; провайдер задаётся в `.env` (`LLM_PROVIDER`) |
| 4 | `agent.py` | Цикл «подумать → написать код → запустить → оценить → улучшить» |
| 5 | `sandbox.py` | Запуск сгенерированного кода в отдельном процессе с таймаутом |
| 6 | `validation.py` | Проверки на утечку данных и переобучение |
| 7 | `report.py` | Итоговый отчёт в `experiments/` |

Другие папки:
- `data/` — датасеты (не попадают в git).
- `experiments/` — результаты запусков и отчёты (не попадают в git).
- `tests/` — тесты pytest.

## Правила кода

- Простой и читаемый код: без лишних абстракций, классов «на будущее» и хитрых трюков.
- Комментарии и docstring — на русском языке.
- Каждая функция делает одну понятную вещь; имена — на английском и говорящие.
- Секреты (API-ключи) только в `.env`, никогда в коде и не в git.
- Новые зависимости добавлять в `requirements.txt` с комментарием, зачем они нужны.
- На каждый реализованный модуль — хотя бы один тест в `tests/`.
- Делать по одному модулю за этап, ничего лишнего сверх задачи этапа.
- После каждого этапа обновлять раздел «Что сделано» ниже.
